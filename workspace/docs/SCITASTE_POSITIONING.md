# SciTaste 的当前研究定位

全项目统一命名 **SciTaste: Learning Scientific Taste for Autonomous Research Decision Making**，目标仍是学习贯穿科研全流程的 Scientific Taste。

当前实施优先级是 **Learning Scientific Taste for Efficient Research Idea Discovery**。吸收 FastResearch 式快速检索、文献分析、研究空白发现和 Idea 构造，形成 Rapid Retrieval → Evidence Synthesis → Idea Construction → Taste-guided Refinement。FastResearch 不作为独立产品品牌或另一套科研主线。

Experiment、Writing、Figure、Review 保留长期规划、已有实现和科学验收要求。Shared Scientific Taste 跨阶段共享科研价值判断、决策反馈和持续改进。视觉 training-free 课题与 SciTasteBench 是统一平台中的研究课题，各自保持原始证据、预算和确认隔离；应用课题的开发收益不能替代 Taste 的因果有效性证据。

四个核心问题：

1. 如何从优秀科研决策中表示并学习 Taste？
2. 如何让 Taste 指导检索、Idea 构造和实验规划？
3. Idea 阶段形成的判断原则能否跨阶段迁移？
4. 在有限时间、算力与检索预算下，Taste 是否提高成果质量？

对应证据需要同信息与预算的强检索/构造控制、冻结开发与确认边界、关键 Taste 干预消融、跨阶段迁移评估及完整成本和负结果。界面完成、信息组织或生成更多候选不会自动满足这些研究门槛。

公开仓库保留原生研究运行时，在 `workspace/` 集成当前信息检索、文献与 benchmark 组织、项目进展、经验、赛马及 CCF A/B 投稿规划入口。旧本机路径和内部 ID 继续兼容，不迁移或重写已冻结实验。
