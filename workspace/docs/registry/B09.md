# BFCL

子领域：GUI与工具Agent。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：ICML 2025 benchmark；ACL 2026 Fission-GRPO 使用 v4

内容与评分：单轮/多轮/irrelevance/agentic；v4 增加 memory/web。AST、执行、状态与响应；v4 Multi-Turn 不等于全总榜

库内采用证据：2 篇录用论文、6 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://gorilla.cs.berkeley.edu/leaderboard.html)。[出处/版本依据](https://proceedings.mlr.press/v267/patil25a.html)

当前提升判断：Qwen3-8B v4 多轮训练后 46.75；错误恢复可拆解

缺口与更新优先级：补 v4 当前 TF 强对照；ICML 2025 综合版不能贴成当前 v4
