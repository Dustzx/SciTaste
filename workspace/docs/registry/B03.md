# BLINK

子领域：视觉感知与空间。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：ECCV 2024；CVPR 2026 P² 与 SenseNova-SI 等录用方法使用

内容与评分：14 任务 / 3807；val 1901，test 1907。选择题；HardBLINK Depth 独立变体；子任务分数不能作全 14 项总分

库内采用证据：2 篇录用论文、74 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/zeyofu/BLINK_Benchmark)。[出处/版本依据](https://zeyofu.github.io/blink/)

当前提升判断：P²在多个子任务已高；semantic correspondence GPT-5 Mini/4B约64%，Gemini2.5Pro74.10；仍需当前目标模型同预算诊断

缺口与更新优先级：已补Standard/Raw Tool/P²；专家输出、像素/调用/shot预算待匹配；HardBLINK Depth独立；原图pilot不并入官方榜
