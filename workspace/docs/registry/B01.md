# ChartQAPro

子领域：图表理解。影响层：B。状态：成绩已收录。核实：2026-10-10。

影响依据（定性）：Findings ACL 2025 基准；START WACV 2026 使用；专项影响判断；CVPR2026 BiPS主会使用

内容与评分：1341 图 / 1948 问题，事实、多选、对话、假设、不可回答。数值容差、年份 exact、文本 ANLS；固定推荐 VLMEvalKit commit；多轮前置答案协议保留

库内采用证据：3 篇录用论文、12 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/vis-nlp/ChartQAPro)。[出处/版本依据](https://aclanthology.org/2025.findings-acl.978/)

当前提升判断：结构/单位/图例绑定值得短筛选；较新通用模型尚需同预算实测

缺口与更新优先级：已补CVPR2026 BiPS主会原表与训练/资源条件；当前模型、原始scorer、同总预算强TF对照仍需实测
