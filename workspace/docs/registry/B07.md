# OmniDocBench

子领域：文档解析与OCR。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：CVPR 2025 基准，多专用解析模型和持续版本榜单采用

内容与评分：多来源 PDF 文本、表格、公式、阅读顺序；当前仓库 v1.7。Edit distance 越低越好；TEDS/CDM 越高越好；MGAM/版本不能混

库内采用证据：1 篇录用论文、6 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/opendatalab/OmniDocBench)。[出处/版本依据](https://openaccess.thecvf.com/content/CVPR2025/html/Ouyang_OmniDocBench_Benchmarking_Diverse_PDF_Document_Parsing_with_Comprehensive_Annotations_CVPR_2025_paper.html)

当前提升判断：整体专用解析器已高，优先复杂表/公式和物理扰动分层

缺口与更新优先级：会议旧版与 v1.5/v1.7 切开；补最新专项难例成绩
