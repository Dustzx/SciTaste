# ChartMuseum

子领域：图表理解。影响层：A。状态：成绩已收录。核实：2026-10-10。

影响依据（定性）：NeurIPS2025 D&B官方录用；CVPR2026 BiPS主会实际采用，成熟图表推理迁移任务

内容与评分：NeurIPS2025 D&B；1162 QA、928图、184来源；dev162/test1000；visual/text/synthesis/visual-text。官方gpt-4.1-mini-2025-04-14 judge；固定prompt与split，近似字符串评分不自动等价

库内采用证据：1 篇录用论文、3 条录用成绩（非全社区统计）。近期热度：成熟图表推理任务；不以旧模型低分推断热度。

入口：[官方资源](https://github.com/Liyan06/ChartMuseum)。[出处/版本依据](https://proceedings.nips.cc/paper_files/paper/2025/hash/ca20efa9cf3703186d91424cf4876f8b-Abstract-Datasets_and_Benchmarks_Track.html)

当前提升判断：CVPR2026 BiPS Qwen2.5-VL-7B26.8→33.5；是历史模型的训练收益，不能替代当前型号headroom；待当前模型同预算验证

缺口与更新优先级：官方judge的授权/费用、当前强baseline、来源分组与接口尚待验收；无本项目实测
