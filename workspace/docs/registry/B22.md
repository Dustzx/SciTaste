# τ²-bench

子领域：GUI与工具Agent。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：ICML 2026 基准；ACL 2026 Fission-GRPO 等采用

内容与评分：retail/airline/telecom；用户也能操作工具。pass@1/pass^k、任务版本、user 模型和 trial 次数分开

库内采用证据：1 篇录用论文、6 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/sierra-research/tau2-bench)。[出处/版本依据](https://proceedings.mlr.press/v306/barres26a.html)

当前提升判断：Fission Qwen3-8B 36.8/32/55，仍有域相关空间；纯 API 恢复对照待查

缺口与更新优先级：GLM-5 simulator 不等于默认 gpt-4.1；补近期冻结模型方法
