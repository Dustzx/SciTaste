# MathVerse

子领域：视觉数学与综合推理。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：成熟视觉数学任务；2025 Findings MathCoder-VL 等采用

内容与评分：同一数学题的 6 种图文信息版本，原题成组。testmini / full 与版本分开；答案抽取和匹配涉及 judge

库内采用证据：1 篇录用论文、2 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/ZrrSkywalker/MathVerse)。[出处/版本依据](https://arxiv.org/abs/2403.14624)

当前提升判断：图像依赖机制比整体低分更有价值；MathCoder 已训练到 46.5 testmini

缺口与更新优先级：补最新 2026 结果、每变体 N 和 judge；不把六变体当独立题
