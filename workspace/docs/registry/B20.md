# HR-Bench

子领域：高分辨率与视觉搜索。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：多个视觉搜索录用方法采用；DeepScan CVPR 2026 明确对照

内容与评分：4K/8K；single/cross-instance。全体 vs 子类；Sandbox 对每题四 option rotations 的 800 不是 800 独立图

库内采用证据：1 篇录用论文、8 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/DreamMr/HR-Bench)。[出处/版本依据](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_DeepScan_A_Training-Free_Framework_for_Visually_Grounded_Reasoning_in_Large_CVPR_2026_paper.pdf)

当前提升判断：DeepScan cross-instance 59.7/57.6 比整体更值得机制诊断

缺口与更新优先级：补 rotation/pixel-budget 匹配；不跨 4K/8K 比
