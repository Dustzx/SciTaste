# gRefCOCO

子领域：开放目标定位与分割。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：CVPR 2023 起；ACL 2026 AnchorSeg 等近期 grounding 方法采用

内容与评分：无目标/单目标/多目标；GRES 分割与 GREC 检测是不同任务。gIoU/cIoU/null acc 与实例 F1 分开；union IoU 不表示全实例匹配

库内采用证据：1 篇录用论文、3 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/henghuiding/gRefCOCO)。[出处/版本依据](https://aclanthology.org/2026.acl-long.938/)

当前提升判断：SetCon 78.4 gIoU 与 AnchorSeg 74.76；生成协议/分割专家代价不同

缺口与更新优先级：补 2026 GREC instance 分数，null 与多目标分层，跨图独立集
