# MMStar

子领域：视觉数学与综合推理。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：原始1500题视觉必需评测；本库已核实CVPR2026 LFM及CA-TTS两项方法使用，属成熟综合迁移任务

内容与评分：1500 多模态选择题。验证 split / 标签 / 采样；综合指标非纯视觉机制

库内采用证据：2 篇录用论文、8 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/MMStarBenchmark/MMStar)。[出处/版本依据](https://arxiv.org/abs/2609.24362)

当前提升判断：Qwen2.5-VL-7B录用表：LFM63.9→66.1；CA-TTS文中60.2→完整71.3（有训练/专家）；近期arXiv VERDICT61.25→65.88，不能跨prompt认定收益大小

缺口与更新优先级：已补近期CVPR主会成绩；LFM training数据命名、CA-TTS ALL权重/完整预算/scorer/新模型revision仍需核实
