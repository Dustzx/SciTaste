# MMMU-Pro

子领域：视觉数学与综合推理。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：ACL 2025 主会；多综合 VLM 推理工作采用

内容与评分：标准 1730，4-option / 10-option / vision variants。多选准确率；variant 不混；thinking、搜索和 oracle 成本

库内采用证据：1 篇录用论文、2 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/MMMU-Benchmark/MMMU)。[出处/版本依据](https://aclanthology.org/2025.acl-long.736/)

当前提升判断：强搜索预印本达 85.6；小模型 41→55.2 可作迁移线索

缺口与更新优先级：补 2026 主会方法，CoT² 预算和完整 standard 设置
