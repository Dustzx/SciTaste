# CharXiv

子领域：图表理解。影响层：A。状态：成绩已收录。核实：2026-10-10。

影响依据（定性）：NeurIPS 2024 D&B；START 与 HierVA 多项近期录用工作使用；CVPR2026 BiPS主会使用

内容与评分：真实科学图表；reasoning val 1000；descriptive 独立任务。val 有标签，test 隐藏；官方自由回答 judge；部分新模型报告改过 GT

库内采用证据：3 篇录用论文、14 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

入口：[官方资源](https://github.com/princeton-nlp/CharXiv)。[出处/版本依据](https://openreview.net/forum?id=cy8mq7QYae)

当前提升判断：HierVA 64.2 与新模型自报 90%+ 口径不同，需先测当前小模型

缺口与更新优先级：已补CVPR2026 BiPS主会原表与训练/资源条件；当前模型、原始scorer、同总预算强TF对照仍需实测
