# AIME 2025

子领域：文本数学与代码推理。影响层：A。状态：成绩已收录。核实：2026-10-09。

影响依据（定性）：NeurIPS 2025 Absolute Zero 及广泛 reasoning 报告采用

内容与评分：30 道竞赛题，注意 2024/25/26 分开。整数 exact；seed/sample/vote/token budget；小 N 不适合单题选优

库内采用证据：1 篇录用论文、4 条录用成绩（非全社区统计）。近期热度：持续跟踪；不能仅凭feed推断热度。

缺口与更新优先级：补 2026 数据独立性与最新同规模分数
