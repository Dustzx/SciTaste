# SciTaste ICLR 2027 writing self-iteration

This case records the use of SciTaste's paper-writing path on the SciTaste
manuscript itself. It is engineering self-evidence and is excluded from the
headline matched-budget effectiveness evaluation.

The intervention replaced generic article packaging with a content-bound venue
contract. The official ICLR 2027 ZIP is fixed at SHA-256
`0d940dfa9398ae99a18f24a85a8a683f367204b6af6d17d2899e60a67102529e`;
only separately hashed registered assets can enter the bundle. The builder
requires the substantive-manuscript assessment, checks anonymous-mode identity
and internal-marker leakage, closes Markdown citations against BibTeX, rejects
duplicate keys, enforces terminal statement order and the one-page AI Use
Statement limit, compiles through pdfLaTeX, and reads the main-text endpoint
from a renderer-owned label.

The first accepted project-owned bundle is
`outputs/projects/scitaste-self-development/papers/scitaste-iclr2027-submission-draft-v1/`.
It contains 4,815 assessed manuscript words, 21 headings, all seven cited BibTeX
keys, no detected identity or internal audit markers, an eight-page main-text
boundary, a one-page AI Use Statement, and a nine-page Letter-sized PDF. The
full repository result is 866 passing tests with 83 percent combined statement
and branch coverage. Project revision 186 selects both the writing acceptance
run and this paper.

Mechanical submission eligibility is not novelty, correctness, blinded-review,
effectiveness, or publication readiness evidence. The paper manifest therefore
keeps `publication_ready` false, and the self-development project remains
non-retrieval evidence.
