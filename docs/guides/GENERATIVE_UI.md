# SciTaste 界面使用与边界

本页描述当前界面职责和使用入口；完整实现历史保存在[旧界面文档](../archive/snapshots/GENERATIVE_UI.pre-20261012.md)。

## 两个相连的入口

| 入口 | 使用目的 | 数据来源 |
| --- | --- | --- |
| workspace 研究工作台 | 文献与 benchmark、项目卡片、分支比较、经验与 CCF A/B 投稿规划 | 本地来源目录、report 投影和原生项目接口 |
| 原生项目界面 | 项目状态、证据、对话、计划、稿件和受约束操作 | `src/scitaste/generative_ui/` 及原生 project runtime |

本地兼容布局保留旧 origin 和项目深链接。公开仓库通过 `workspace/` 接入原生 runtime，具体启动方式以仓库 README 和 workspace 使用文档为准。

## 看进展的顺序

先看项目当前科学问题和待完成交付，再看分支处于准备、运行、评分、停止还是确认。最后打开对应结果和证据。原生指标、适配任务结果、工程有效率与科学收益分别解读；开发收益不能自动换算成论文完成度。

项目介绍可能来自独立审阅的说明文档，进度卡来自动态报告；两者的来源和复核时间应分别显示。修复过期进展应更新其真正来源，避免覆盖介绍或旧审阅记录。

## 编辑与执行

界面可以提出或接收有来源的计划和文档建议。真正的项目变更必须经过既有版本、字段和权限校验；网页刷新、来源预览和文档阅读不启动实验。

跨项目共享经验显示来源、适用范围和验证状态。经验池展示不等于经验已进入决策库；Writing 和赛马使用经验时应能查到具体案例、版本及采用或弃权记录。详见[经验接入规范](../taste/EXPERIENCE_INTEGRATION.md)。
