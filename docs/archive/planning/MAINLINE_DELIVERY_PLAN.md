## 平台功能与论文贡献分别维护

| 层次 | 本轮交付 | 不应宣称 |

## 通用项目使用与当前记录

所有项目可使用同一模型/API；没有配置的项目返回 `configured=false`，不伪造
期限、结果或计划。新项目默认预留 `docs/project/SUBMISSION_PLAN.md`。
本轮不替其它项目决定题目/期限，也不修改 Excluded study 研究内容。

```bash
.venv/bin/scitaste project submission-plan status --project-id scitaste-self-development
.venv/bin/scitaste project submission-plan set --plan <project-plan.json> \
  --expected-revision <current-revision> --author <owner> --reason <change-reason>
```

完整输入为 `SubmissionPlanDraft`：项目/会议、目标、时区明确的内部期限、
责任角色、工作依赖、日期、完成条件与证据。修改使用整体计划 CAS，不覆盖
他人并发更新。完成项必须有项目内文件哈希；证据变化或依赖未完成时不能
继续宣称有效完成。当前计划是 `PROJECT.json` 的 `submission_plan`，人类视图为
`docs/project/SUBMISSION_PLAN.md`；历史仅追加到一个有上限的 JSONL 容器。
保存计划不启动任务，不改变 `publication_ready`，不确认外部会议提交。

- `outputs/projects/scitaste-self-development/docs/project/SUBMISSION_PLAN.md`

  由现有 Generation as Content 项目接口读取；不另建一套界面或控制器。
