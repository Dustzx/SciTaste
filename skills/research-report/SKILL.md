# 科研 Idea 汇报整理

目标是让非项目作者在约一分钟内回答：为什么做、具体怎么做、别人已做到什么、额外价值是什么、证据支持到哪一步。准确表达一个可能有价值但未证明的机制，优于堆积术语或把候选写成有效贡献。

## 先确定事实与汇报范围

- 读取现有汇报入口及项目约定，再核当前状态、结果、计划和与主张有关的源码/方法原文；先定位实际数据流，不能从项目名或抽象愿景反推实现。
- 源研究文档维护事实与决策，汇报是投影。只更新授权的简报/展示/导出；不为配合故事改结果、开实验、改研究路线或新增资源。需要执行实验时另依用户授权和实验约定处理。
- 近期进度更新是汇报的附属工作，设一次源核查截止，不持续追赶并发实验；关键变化记录待下次复核。
- 分开维护“本次整理时间”和“源记录核查时间”。并发窗口晚于核查的更新提示待复核；本地记录不能证明远端当前存活。
- 已审阅近邻材料可复用；涉及新颖性判断、最新方法或未给出原文的具体论文时检索原文/官方源码。主会、Findings、Workshop、预印本分别标注，未检索到同款不写首创。

## 让动机产生一个具体研究问题

1. 从任务中的具体失败出发，说明输入、目标和失败的实际后果；例子可以是明确标注的说明性例子。
2. 解释强已有方案如何处理它，以及仍待验证的缺口。若缺口仅为假设，明说；不把本方特有术语当作任务的必要能力。
3. 用“改变什么机制，预期改善什么能力”表达 idea，并交代为何这一改变可能奏效。把机制描述与实验验收条件分开。
4. 主动尝试朴素解释：是否等价于 bbox＋ID、普通缓存/检索、更多计算、已有损失/监督、普通集合运算或格式变化？若是，收缩主张，明确仍值得验证的部分。

避免“现有方法都无法……”“填补空白”“可复用/可组合所以新颖”等无依据断言。研究价值可以清楚而新颖性暂不成立。

## 逐项讲明与近邻的差别

挑选直接挑战核心机制的近邻，不按名气或年份机械列论文。每项交代：**它具体做什么 → 已覆盖什么 → 我们实际改变什么 → 这个改变为何可能有价值 → 比较完成度**。

对照问题、输入信息与权限、表示单位、干预位置、监督和目标、训练/推理路径及预算。实现差异不是增益证据；已有组件的并列也不能自动推出完整机制已被覆盖。不能靠把邻近方法描述得弱来制造区别。

“原子/地址/状态/经验/信用”等词须给操作定义。例如视觉编码要区分二进制位、区域原子和对象组合；可序列化或可解码，不等于模型学会未见组合。

## 让方法可以沿一次实际调用走完

- 给出输入、关键中间对象、变换或决策、最终输出及读出方式。说明模型/工具分别负责什么，必要时附关键源码入口。
- 训练写清监督从哪里来、哪些参数或状态改变；推理写清实际可用信息、调用顺序、历史/缓存及失败处理。目标标签、外部提案和离线字典不能隐去。
- 用少量步骤讲完整路径，流程图中的箭头必须能用一句话解释。保留现有详细配置和结果表，不让编号/损失名占据首屏。
- 为关键组件标明：已实现、已测但结论有限、候选未实现、历史停止或待核。已测旧方法与新候选分开，不能把新概念贴在旧图上当实现。
- 选一条真实样例或说明性例子，展示输入→中间表示/动作→输出。说明性例子明确标注，不给伪造预测/成绩；没有合适例子时说明缺口。

## 建立短入口，保留展开与证据

复用项目既有结构。推荐阅读顺序：**一句话问题与机制 → Motivation → 核心增量与近邻差异 → 输入输出/实现图/例子 → 当前证据 → 最关键未知**。短入口不重复全套分数，主实验与相关工作表仍保留模型、划分/曝光、分母、预算和来源。平台本身用于展示时，把真实页面截图、导航链接与采集时间纳入图文包；截图与科学证据分开，不能截loading或用演示内容冒充结果。

正、零、负结果和未知同报；局部诊断、作者报告、稿件报告、系统效果、机制效应、独立确认分别标识。方法尚未锁定时不硬凑 novelty；停止分支仍讲清曾检验的机制。

在SciTaste工作台使用时，读取 [references/workbench.md](references/workbench.md) 确认资料接入和平台支持范围；输出结构参考 [references/report-template.md](references/report-template.md)。其他项目保留其既有汇报格式。

## 完成前用读者问题检查

- 不看 run 编号，能否解释任务、失败及影响？
- 能否沿步骤说明一次训练和一次推理，指出外部信息从哪里进入？
- 能否用一句话描述最接近方法，并指出一个可验证的实质差别？
- 是否把表示容量、解码规则或更大预算误当成组合泛化/学习收益？
- 能否分别说出已有支持、被否定的解释和最关键未知？
- 简报、简介、图示和导出是否描述同一版本？链接、来源和现有页面是否可用？

按变更范围验证资料/链接和网页/导出；不为措辞变更启动科学实验。汇报末尾给出入口与实际更新范围，不宣称顶会就绪。
